# 云端部署安全基线

## 默认行为

- UI 使用临时任务仓库，不持久化简历、证据或跨用户历史。
- 历史记录只保存在当前 Streamlit 会话中，最多 10 条。
- DeepSeek 必须由用户主动勾选授权才会调用。
- DeepSeek 调用受单用户小时、单用户每日和全局每日三层限额保护。
- 手机号、邮箱和微信号会在发送模型前脱敏。
- PDF、DOCX、TXT 会检查文件签名、大小、页数、解压大小和提取字符数。
- 生产模式关闭 FastAPI Swagger，并默认关闭历史查询接口。

## Streamlit Cloud 上线检查

1. Git 仓库中不存在 `.env`、`secrets.toml`、真实简历和 SQLite 数据库。
2. Secrets 中设置 `APP_ENV="production"` 和 DeepSeek 配置。
3. 优先将应用设为私有并通过邮箱邀请。
4. 如需应用内登录，配置 OIDC、`REQUIRE_LOGIN="true"` 和邮箱白名单。
5. 首次公开时使用虚构测试简历，检查限流和清除会话功能。
6. DeepSeek 平台侧设置余额告警，并定期轮换密钥。

## 剩余边界

内存限流适合单实例作品集演示，实例重启后计数会重置。正式多实例产品应改用 Redis 等共享存储，并将审计记录写入受控数据库。
